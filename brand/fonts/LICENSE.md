# Fonts

Both families are licensed under the **SIL Open Font License 1.1**, which allows commercial use,
embedding in video, and redistribution:

- **Fraunces** — Undercase Type (Phaedra Charles, Flavia Zimbardi). Variable serif, used for titles,
  thumbnails and cards at weights 400 / 600 / 900.
- **Inter Tight** — Rasmus Andersson. Used for labels, episode numbers and credits.

Files here are static Latin-subset TTFs converted from the `@fontsource` npm distributions so the
render pipeline (Pillow) can load them without a webfont decoder.

Keep this attribution in the repo; it is also the answer to any "what music/font did you use"
copyright claim question on YouTube.
